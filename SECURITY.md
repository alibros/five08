# Security policy

Five08 is a client-side application and does not operate a backend service.

Please report a security issue privately by emailing [ali@forestofrods.com](mailto:ali@forestofrods.com). Do not open a public issue for vulnerabilities involving unsafe project imports, browser storage, embedded artwork, export injection, or dependency compromise.

Include a clear reproduction and affected browser where possible. Supported security fixes target the current `main` branch.
